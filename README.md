# probe — служебный адрес проверки связи

Приложение «ЧАШКА КОФЕ | VPN» (iPhone и Mac) проверяет здесь, что трафик действительно идёт через туннель: скачивает
`64k.bin` (65 536 случайных байт) или `ok` (задержка). Адрес нарочно не на основном сервере сервиса: если основной
сервер прилёг, приложение не должно принимать это за мёртвый туннель. И нарочно не в России: по правилам подписки
российские адреса идут мимо туннеля, и такая проверка туннель бы не проверяла.

Персональных данных здесь нет. Не удалять, не переименовывать и не менять размер файлов без согласования с
серверной стороной (03.11.2026, решение оператора).
